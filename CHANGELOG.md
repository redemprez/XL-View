# Changelog

## 0.7.0 — First GitHub release

- Added Settings → Control labels: font family, 75–200% scale, bold text, foreground color and optional background color, with live preview and reset.
- Label preferences persist independently of controller modes and presets.
- Retained the controller layout, bottom slot bank and right-side editing panel.
- Includes the existing controller read/write workflow, MIDI feedback, single/multiple selection editing, versioned preset library, optional send preview, automatic backups and readback checks.

The GitHub release publishes the existing 0.7.0 Windows installer. Repository documentation, license and CI were added for publication; the installer binary was not rebuilt for these documentation additions.

Earlier local development versions are not separately published here.
